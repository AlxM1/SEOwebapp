# TradeConnect - Tradesmen Platform

A mobile platform connecting customers with skilled tradesmen like electricians, plumbers, locksmiths, and other handymen. Similar to Uber/Airbnb for home services.

## Recent Updates

### Logo Design
Created a professional logo component (`src/components/Logo.tsx`) featuring:
- **House symbol** representing home services
- **Wrench icon** representing skilled tradesmen and tools
- **Color scheme**: Navy blue (#004E89) and orange (#FF6B35) for trust and energy
- **Scalable**: Available in multiple sizes
- **App icon version**: Rounded corners for mobile app icons
- **Connection dots**: Subtle elements representing the platform connecting customers with tradespeople

The logo is displayed on the home screen with various size previews.

## Tech Stack
- Expo SDK 53
- React Native 0.76.7
- TypeScript
- NativeWind (TailwindCSS)
- React Native SVG for logo rendering

## Project Structure
- `src/app/` - Expo Router file-based routes
- `src/components/` - Reusable UI components including Logo
- `src/lib/` - Utility functions
- `public/images/` - Static image assets
